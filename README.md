# MIVA Open University Student Portfolio

A five-page responsive portfolio built with semantic HTML, an external CSS stylesheet, and JavaScript.
## Pages
- `index.html` — Home
- `about.html` — About Me
- `projects.html` — Projects (includes a semantic HTML table)
- `planner.html` — Academic Planner (add, complete, undo, delete, clear; tasks persist with localStorage)
- `contact.html` — Contact form with required-field, email and digits-only phone validation; HTML5 video and audio controls

## Assets
- `images/moses-profile.png` — supplied profile photograph
- `images/*.svg` — original vector dashboard and planner illustrations
- `media/portfolio-audio-cue.wav` — short original two-tone UI audio demonstration

## Before submitting
- Replace generic LinkedIn/GitHub/YouTube links with your actual profile URLs.
- Add your preferred email address and phone number to `contact.html`.
- Replace sample project descriptions/screenshots with real project work when available.
- Replace the sample video URL in `contact.html` with your own portfolio introduction video if required.
- The contact form validates in the browser but does not send email until connected to a backend or form service.
- The first two projects are labelled as demonstration concepts rather than completed client projects.
